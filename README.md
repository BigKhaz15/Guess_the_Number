Number Guessing Game
My first completed game: a C++ terminal game where you guess a random number between 1 and 100.

How to Play:
Enter a guess and follow the Too high! or Too low! hints until you find the secret number. When you win, the game displays how many valid guesses you made.
Features
- Random secret number generated for each run.
- Higher/lower feedback and a guess counter.
- Input validation for empty entries, letters, decimals, and out-of-range numbers.
- Trims surrounding whitespace while rejecting spaces between digits.
- Exits when input becomes unavailable.
Input must contain one to three digits after trimming and represent a number from 1 to 100. Rejected entries do not count as guesses.
Running the Game
1. Open the solution in Visual Studio with C++ support installed.
2. Build the project.
3. Run and follow the terminal prompts.

Uses the C++ standard library; no external libraries are required.

What I Practiced: Functions, loops, conditions, random number generation, string processing, input validation, and handling the end of input.
